# **App Name**: Galarraga Portfolio

## Core Features:

- SEO Metadata: Implements SEO metadata to enhance search engine visibility. Uses keywords: 'Desarrollador Web Freelance', 'Full Stack Developer', 'Fintech', 'Alta Concurrencia', 'Node.js', 'React', 'JavaScript'.
- Hero Section: Displays a hero section with a title, subtitle, and clear call-to-action buttons to showcase the developer's value proposition.
- About Me Section: Presents the developer's experience and skills, highlighting expertise in JavaScript, Node.js, React, TypeScript, Microservices, and high-concurrency systems.
- Project Portfolio: Showcases selected projects with descriptions, key technologies, and links to the GitHub repositories. This feature may use AI tool to extract relevant repo and technology data, automatically
- Contact Form: Integrates a contact form for potential clients to send project inquiries directly to the developer.

## Style Guidelines:

- Primary color: Deep midnight blue (#2C3E50) for a professional and trustworthy feel.
- Background color: Light gray (#F0F4F8) for a clean and modern look.
- Accent color: Vibrant teal (#22A39F) for call-to-actions and highlights.
- Headline font: 'Space Grotesk' (sans-serif) for a computerized, techy, scientific feel. Body font: 'Inter' (sans-serif) as the body to maximize readability. 
- Use a clear, modular layout, with a navigation bar, hero section, 'about me', portfolio, and contact sections.
- Incorporate minimalist icons to represent skills and technologies.
- Implement subtle animations (e.g., hover effects, transitions) to enhance user engagement.
